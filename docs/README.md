# Docs

The main entry point for repository documentation is the root `README.md`.

Use this folder for focused guides:

- `architecture.md`: current structure, boundaries, and deployment direction
- `local-development.md`: setup, schema workflow, and reset steps
- `auth-and-multitenancy.md`: login flow, claims, and tenant isolation rules
- `request-flows.md`: how key UI actions move through the app
- `data-model.md`: practical entity and persistence overview
- `contributing.md`: placement and maintenance guidance for changes

If you add a new major subsystem, add a focused doc here instead of overloading `architecture.md`.
